## Состав

| Файл | Что это |

## Автомат за 20 секунд

```
S0 ПОКОЙ → S1 ВХОД → S2 ДЕЛО → S3 СВЕРКА → S4 ПЛОМБА → S5 УБОРКА → S0
                                    ↓ авария ↑ recover
                                   S6 АВАРИЯ
```

## Такт (ритуал)

```bash
python3 house_fsm.py enter  --mandate "репо X: задача Y"
python3 house_fsm.py work   --task "что сделано"
python3 house_fsm.py verify --facts "HTTP 201, sha256=…"
python3 house_fsm.py seal                    # пломба: журнал + SHA256
python3 house_fsm.py clean                   # токены стёрты, tmp пуст
python3 house_fsm.py status                  # S0 покой подтверждён
```

Авария: `python3 house_fsm.py abort --reason "…"` → `recover` → обычное завершение такта.

## Гарантии

- **Детерминизм**: запрещённый переход = `REJECTED` в журнале, не исключение
- **Свидетельства**: каждое действие — байты (SHA, коды), не обещания; UNKNOWN ≠ FALSE
- **Гигиена токенов**: только `~/.house-fsm/tmp/` с правами 600, стёртие в `clean`, G1 убирает утечки из env сам
- **Эмерджентный порядок**: H1–H5 истинны у каждого такта → дом упорядочен без надзора

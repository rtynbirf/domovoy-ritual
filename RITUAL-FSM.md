# УСТАВ ДОМА · РИТУАЛ КАК КОНЕЧНЫЙ АВТОМАТ

> **Закон дома:** человек не делает того, что может сделать агент.
> Поработал → сделал → убрал за собой. Ни одного хвоста. Ни одного уведомления.
> Всё закрывается и решается самостоятельно. Это не просьба — это автомат.

**Версия 1.0 · 2026-11-11 · мандат Хозяина**

---

## 0. Аксиомы дома (не обсуждаются)

| № | Аксиома | Следствие |
|---|---------|-----------|
| A1 | **Дом — конечный автомат.** У каждого действия агента есть ровно одно текущее состояние и конечный набор допустимых переходов. | Нет состояния «подумаю потом». Либо переход выполнен, либо автомат остался на месте. |
| A2 | **Каждый переход оставляет свидетельство** (машинный вывод: SHA, код ответа, счётчик). Не обещание — байты. | UNKNOWN ≠ FALSE. |
| A3 | **Никаких открытых дверей.** Сеанс завершается только в состоянии `S0 ПОКОЙ` или `S6 АВАРИЯ→S0` с записью в журнал. | «Ушёл по Ctrl+C» — нарушение устава. |
| A4 | **Уборка равна работе.** Сеанс без уборки = несостоявшийся сеанс. | Токены в `/tmp` с правами 600, стёртые в конце; ветки влиты или удалены; issues закрыты или перенесены. |
| A5 | **Аддитивность.** Добавлять можно; удалять и переписывать историю — нельзя. Откат — только `git revert`. | История — свидетельство, а не черновик. |
| A6 | **Чужая орбита неприкосновенна.** Аккаунт общий; автомат работает только в своём мандате. | Конфликт орбит невозможен по построению. |
| A7 | **Решение по умолчанию существует всегда.** Автомат не ждёт человека: на каждый входной случай есть табличный дефолт (§4). | Ноль уведомлений: уведомление — это непринятое решение. |

## 1. Автомат: формальное определение

```
M = (S, Σ, δ, s₀, F)

S  = {S0, S1, S2, S3, S4, S5, S6}          — конечные состояния
Σ  = {enter, work, verify, seal, clean, abort, recover, heartbeat}
δ  = S × Σ → S                             — детерминированная функция переходов
s₀ = S0 ПОКОЙ                              — стартовое состояние (дом спит)
F  = {S0}                                  — единственное финальное состояние
```

### 1.1 Состояния

| Состояние | Имя | Инвариант состояния (что обязано быть истинным) |
|-----------|-----|--------------------------------------------------|
| **S0** | ПОКОЙ | Токенов в среде нет; `tmp/` пуст; все сеансы закрыты в журнале; HEAD = origin/HEAD |
| **S1** | ВХОД | Токен в `/tmp` с правами 600; мандат (список репо/действий) зафиксирован; таймстемп старта записан |
| **S2** | ДЕЛО | Каждый артефакт изменён только в орбите мандата; никаких force-push; изменения в рабочей области |
| **S3** | СВЕРКА | Каждое действие имеет машинное свидетельство: HTTP-код, SHA256, вывод API; UNKNOWN помечен |
| **S4** | ПЛОМБА | Журнал сеанса дописан; ворклог обновлён; git-бандл + SHA256 созданы для затронутых репо |
| **S5** | УБОРКА | Токены стёрты и подтверждено отсутствие; tmp пуст; issues/ветки закрыты; `git status` чист |
| **S6** | АВАРИЯ | Причина зафиксирована; ущерб описан; план восстановления записан. Единственный выход — recover → S3 |

### 1.2 Таблица переходов δ (полная, без пробелов)

| Из \ Событие | enter | work | verify | seal | clean | abort | recover |
|---|---|---|---|---|---|---|---|
| **S0** | →S1 | запрет | запрет | запрет | запрет | →S0 (nop) | запрет |
| **S1** | запрет | →S2 | запрет | запрет | →S5¹ | →S6 | запрет |
| **S2** | запрет | →S2 (продолжение) | →S3 | запрет | →S5¹ | →S6 | запрет |
| **S3** | запрет | →S2² | →S3 (досвидетельствование) | →S4 | →S5 | →S6 | — |
| **S4** | запрет | запрет | запрет | →S4 (пломбирование следующих) | →S5 | →S6 | — |
| **S5** | запрет | запрет | запрет | запрет | →S0 | →S6 | запрет |
| **S6** | запрет | запрет | →S3³ | запрет | →S5 | →S6 | — |

¹ Ранний выход: разрешён только если работы ещё не начаты или полностью откачены (revert).
² Свидетельство не полно — автомат честно возвращается работать, не рисует «зелёное».
³ Аварийный путь: сначала собрать свидетельства ущерба, потом пломба и уборка.

**Запрещённый переход = исключение.** Автомат не «пытается» выполнить недопустимый переход — он его отклоняет и пишет в журнал строку `REJECTED: S{from} ×{event}`. Отклонение не ошибка: это работа автомата.

## 2. Guard-условия (шлюзы переходов)

Переход выполняется **только если** все guard-ы истинны. Ложь guard-а → автомат либо чинит условие сам, либо уходит в S6.

| Переход | Guard | Как автомат обеспечивает сам (без человека) |
|---------|-------|---------------------------------------------|
| S0→S1 | G1: среда чиста | Проверка: нет `GH_TOKEN*` в env, нет файлов в `tmp/`. Есть — стереть и войти |
| S1→S2 | G2: мандат непуст | Мандат пуст → сеанс не нужен → clean → S0 |
| S2→S3 | G3: орбита соблюдена | `git remote -v` + белый список мандата; чужое → REJECTED + S6 |
| S3→S4 | G4: свидетельства полны | Каждому действию сопоставлен байт-факт; дырка → вернуться в S2 и доделать |
| S4→S5 | G5: пломбы записаны | SHA256 бандлов в журнале; отсутствие → дописать |
| S5→S0 | G6: дом чист | Скан env+`tmp`+`git status` по всем репо мандата; грязь → дочистить, повторить |
| S6→S3 | G7: ущерб задокументирован | Нет записи ущерба → нельзя выйти из S6 |

## 3. Ритуал (исполнение автомата человеком-или-агентом)

Слово «ритуал» здесь — точный алгоритм. Семь шагов, ноль решений «на месте»:

```
1. ВОШЁЛ      : python3 house_fsm.py enter   # S0→S1: токен в tmp/600, мандат, таймстемп
2. РАБОТАЛ    : python3 house_fsm.py work    # S1→S2: дела по мандату (агент делает сам)
3. СВЕРИЛ     : python3 house_fsm.py verify  # S2→S3: факты по каждому действию
4. ЗАПЛОМБИРОВАЛ: python3 house_fsm.py seal  # S3→S4: журнал+бандл+SHA256+ворклог
5. УБРАЛСЯ    : python3 house_fsm.py clean   # S4→S5: токены стёрты, двери закрыты
6. ВЫШЕЛ      : python3 house_fsm.py status  # S5→S0: подтверждение покоя (или REJECTED)
7. ЕСЛИ АВАРИЯ: python3 house_fsm.py abort  # любой→S6; потом recover (G7)
```

Один полный цикл = **такт дома**. Рой из N агентов выполняет такты независимо; дом остаётся в порядке, потому что каждый такт заканчивается в S0.

## 4. Таблица решений «всё решаю сам» (ноль уведомлений)

Уведомление — это непринятое решение. Поэтому для каждого встреченного случая у автомата есть дефолт. Решай по таблице, не спрашивай.

| Случай | Дефолт-решение автомата | Состояние |
|--------|--------------------------|-----------|
| Токен истёк / 401 | Сеанс → S6, журнал «токен мёртв», уборка tmp, Хозяин узнает из журнала (не из пинга) | S6→S3 |
| Репо вне мандата | REJECTED + запись; не трогать | S2 (остаться) |
| CI красный на чужом репо | Записать факт в журнал сеанса; не чинить чужую орбиту | S3 |
| CI красный на своём | Править сам; если 3 попытки подряд — откат revert, факты в журнал | S2→S3 |
| Merge-конфликт | `git fetch` + rebase; конфликт → revert своего шага и перезапуск такта | S2 |
| Недостаёт прав (403) | Факт в журнал → S6 (выход без ущерба) | S6→S3 |
| Сеть легла (timeout ×3) | S6 с сохранением сделанного (коммиты локальны), recover позже | S6→S3 |
| Issue не по адресу | Закрыть с комментарием-маршрутизацией (куда переносить), не спорить | S2 |
| Артефакт >100 МБ в репо | Вынести в release-vault, ссылку в README, факт в журнал | S2→S3 |
| Пустой репо без пользы >30 дней | Предложить архивацию в журнал следующего аудита (не удалять самому) | S3 |
| Обнаружен чужой секрет | НЕ печатать, НЕ копировать; факт + файл + SHA в журнал; S6 | S6→S3 |
| Двойная уборка (S5 уже чист) | Идемпотентно: повтор → подтверждение чистоты → S0 | S5→S0 |

## 5. Инварианты целого дома (эмерджентный уровень)

Каждый такт каждого агента — локальный FSM. Дом в целом жив, пока глобальные инварианты истинны:

- **H1 · Покой достижим**: из любого состояния существует путь в S0 (проверяется: у каждого цикла есть clean).
- **H2 · Свидетельство монотонно**: журналы только растут (append-only), пломбы не переписываются.
- **H3 · Орбиты не пересекаются**: одно репо — максимум один активный такт (lease через issue в polimat-hub).
- **H4 · Токен не переживает такт**: среднее время жизни токена ≤ длительности сеанса.
- **H5 · Ноль висящих дверей**: `open issues по орбите` → к нулю к концу волны; перенесённые issue ссылаются на новое место.

Если H1–H5 истинны — дом **эмерджентно упорядочен** без единого приказа сверху: порядок — свойство композиции тактов, а не надзор.

## 7. Запреты (анти-ритуал)

1. Оставить токен в env, истории shell, файле репо — **никогда**.
2. Force-push, переписывание истории, удаление чужого — **никогда**.
3. «Доделаю завтра» без S4/S5-записи — **никогда**: завтрашний сеанс начинается с чтения журнала, а не с памяти.
4. Уведомление вместо решения — **никогда** (см. §4).
5. Участие в споре с другим агентом в issue — **никогда**: маршрутизация, не полемика.

## 8. Манифест

Дом — не набор репозиториев. Дом — автомат, который **сам** доводит каждый такт до покоя.
Хозяин задаёт мандаты и читает журнал. Остальное — движение δ.

**Поработал → сделал → убрал за собой. Такт замкнулся. Дом в покое.**
